# 🚀 Como Rodar o Projeto

## 1. Clone o repositório

```bash
git clone https://github.com/seuusuario/lin-kuei-experience.git
```

## 2. Entre na pasta do projeto

```bash
cd lin-kuei-experience
```

## 3. Instale as dependências

```bash
npm install
```

## 4. Execute o projeto

```bash
npm run dev
```
